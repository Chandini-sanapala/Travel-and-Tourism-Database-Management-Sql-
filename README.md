# Travel and Tourism Management System (SQL)

## 📌 Project Overview
This project is a Travel and Tourism Management System built using SQL. It demonstrates how relational databases can be used to store, manage, and analyze real-world travel data such as tourists, destinations, bookings, and guides.

---

## 🗂 Database Structure
The project uses a structured database schema named `Travel_Tourism` consisting of four tables:

- **Tourists** – Stores tourist details (name, country, age)
- **Destinations** – Stores travel destination information (location, category)
- **Bookings** – Stores booking details linking tourists and destinations
- **Guides** – Stores guide details and their assigned destinations

Primary and foreign keys are used to establish relationships between tables.

## 🔍 Key Queries Implemented
- Tourists filtered by country
- Destinations filtered by category and location
- High-cost and top bookings analysis
- Total and average booking cost calculations
- Tourist-destination-guide relationship queries
- Identification of unbooked destinations
